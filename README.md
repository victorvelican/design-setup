# Design setup: guardrails for building better design with AI

Design guardrails for TareCount (tarecount.com), a product built and shipped by one founder directing AI coding agents. The rules live in files, the values live in tokens, and every change is looked at on a phone before it goes live.

Everything is in the `design-setup/` folder:

- `design/BRAND.md` the look: palette roles, typography, spacing, corners, shadow, motion
- `design/tokens.css` the same rules as CSS custom properties, the only place values live
- `design/copy-rules.md` what the text may and may not say, and how it is enforced
- `design/imagery.md` what generated images and films may and may not show
- `guardrails/AGENTS.md` rules an AI coding agent must follow on this design
- `guardrails/CHECKLIST.md` the path from a change to production, in order
- `examples/` screenshots of the rules in use
